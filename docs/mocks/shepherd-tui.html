Project manager

A Claude Code session you talk to, with shepherd's MCP tools, that runs the other agents for you. Opens with ctrl-b p. On the right: what its agents are working on, and what's waiting on you.

shepherd — 120×36

    
    
      
  • just a claude sessionThe PM is an ordinary Claude Code PTY, launched with a shepherd MCP server: status, read_pane, send, answer, new_session, stop. You talk to it like any agent. Shepherd only adds the panel.
    • 
      
  • same events as youIts tool calls turn into the same host events as your keystrokes. The status page and the events feed show what the PM did, and the panel tags each working agent with the last thing the PM told it.
    • 
      
  • two listsWorking shows each busy agent with the last thing the PM told it. Waiting on you collects every decision, whether an agent asked it or the PM raised it, with the question on its own line.
    • 
      
  • asks with a pickerWhen it needs a call it asks one question with a recommended option, using Claude Code's own picker. Your answer goes back through the PM, which relays it to the agent.

Status page

        
Every agent on every machine in one table. Opens with ctrl-b s. Whatever needs you sorts to the top and can be answered without attaching.

      

      

        
        
      

    

    
shepherd — 120×36

    
    
      
  • triage firstThe table groups by what you owe the agent: needs you, working, idle, exited. The header counts each group so you can check the backlog from across the room.
    • 
      
  • answer in placeThe preview shows the selected agent's live pane. y/a/n answer a permission prompt and ⏎ attaches. You only switch sessions when you want to talk to an agent.
    • 
      
  • events + loopsThe feed is the same event stream loops subscribe to. The title shows how many loops are watching, which leaves room for "when PR checks fail, tell the agent".
    • 
      
  • broadcastThe input line messages the selected agent. tab widens the target to a group (all working, all on devbox) so the orchestrator flow is built in.

Subagents in the sidebar

        
A session's badge counts its live subagents. ⇥ expands the tree under the session. Selecting a subagent shows its transcript read-only.

      

      

        
        
      

    

    
shepherd — 120×36

    
    
      
  • badge = live count▸4 when collapsed, ▾4 when expanded. Finished subagents stay in the tree, dimmed, until the parent's turn ends, then drop out of the count.
    • 
      
  • attention bubbles upIf a subagent is blocked on permission, its parent's glyph turns ▲ even while the parent is working. Otherwise you'd miss it inside a collapsed tree.
    • 
      
  • one row per subagentChildren get a single line: branch, glyph, agent type, task. Two lines each would push the other sessions off screen.
    • 
      
  • read-only drill-inA subagent has no PTY of its own. Its transcript comes from the agent's hook or log stream, so the pane says it's read-only and where to answer.

Multiple machines

        
Each machine gets a name and a color. The color follows its sessions everywhere: sidebar line two, the command center and the new-session picker.

      

      

        
        
        
      

    

    
shepherd — 120×36

    
    
      
  • flat is the defaultAs the manifesto says: one list, newest first, with the machine on line two. Attaching to a remote session looks like a local one. Only the footer names the link and its latency.
    • 
      
  • grouped on demandg regroups the sidebar under machine headers, each with its state and link (direct, relay, offline). An offline machine keeps its sessions, dimmed, so you can still see what was running.
    • 
      
  • machines panelctrl-b m lists the peers with link, agent and worktree counts and host build, so a stale host shows up here as well as at hello. Pairing a new machine is one ticket.
    • 
      
  • where, then whatNew session asks for the machine first (it defaults to the last one used), then the agent profile. Offline machines are listed but can't be chosen.
